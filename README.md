# 坦克大战 · Tank Battle

一个用纯 HTML + CSS + JavaScript（Canvas）实现的经典「坦克大战 / Battle City」网页版复刻，单个 `index.html` 文件即可运行，无需任何依赖。

## 玩法

- 守住地图底部的基地（老鹰图标），消灭所有敌方坦克即可过关。
- 每过一关，敌人数量更多、移动更快。
- 你有 3 条生命，基地被摧毁或生命耗尽则游戏结束。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W A S D` / `方向键` | 移动坦克 |
| `空格` | 开炮 |
| `P` | 暂停 / 继续 |
| `Enter` | 开始 / 重新开始 |

## 图块说明

- 🧱 **砖墙** — 可被子弹摧毁
- ⚙️ **钢墙** — 不可摧毁
- 🌊 **水域** — 阻挡坦克与子弹
- 🌿 **草丛** — 可通行、可藏身（遮挡坦克）
- 🦅 **基地** — 被摧毁即游戏结束

## 运行方式

直接用浏览器打开 `index.html` 即可。也可以本地起一个静态服务器：

```bash
# Python 3
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 技术实现

- 纯原生 JavaScript，无外部依赖
- `<canvas>` 逐帧渲染，`requestAnimationFrame` 游戏循环
- Web Audio API 合成音效
- 网格地图 + AABB 碰撞检测
- 敌人生成队列、粒子爆炸特效、无敌重生等经典机制
